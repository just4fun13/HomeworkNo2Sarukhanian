# Анализ финансовой отчётности российских компаний (RFSD)

Домашняя работа № 2 по курсу «Инженер-архитектор в сфере искусственного интеллекта».

## Описание проекта

Проведён разведочный анализ (EDA) финансовой отчётности российских компаний на основе датасета [RFSD](https://github.com/irlcode/RFSD).

**Цель:** исследовать распределения финансовых показателей, выявить аномалии и определить взаимосвязи между характеристиками компаний.

## Этапы работы

1. **Подготовка данных.** Из первых 10 000 записей датасета выбраны 1000 наблюдений с заполненным показателем активов. Для анализа отобраны 20 финансовых показателей с учётом их заполненности.
2. **Описательная статистика.** Рассчитаны средние значения, медианы, стандартные отклонения, квартили и доли пропусков.
3. **Анализ распределений.** Построены гистограммы активов, выручки и чистой прибыли. Для лучшей визуализации использованы логарифмические преобразования.
4. **Корреляционный анализ.** Построена матрица корреляции Пирсона, исследованы наиболее сильные взаимосвязи и проведено сравнение с корреляцией Спирмена.
5. **Анализ выбросов.** Построены диаграммы рассеивания и исследовано влияние экстремальных наблюдений на коэффициенты корреляции.

## Основные результаты

- Распределение активов и выручки характеризуется выраженной правосторонней асимметрией.
- Обнаружено скопление компаний с одинаковой небольшой стоимостью активов, предположительно связанное с особенностями формирования собственного капитала.
- Среди компаний с известным финансовым результатом 78% прибыльны, 20,2% убыточны.
- Корреляция Пирсона между прочими доходами и расходами изменилась с −0,9999 до −0,5929 после исключения 10 крупнейших по прочим доходам наблюдений, что демонстрирует чувствительность коэффициента к экстремальным значениям.
